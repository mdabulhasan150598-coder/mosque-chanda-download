# Mosque Chanda App

A Bengali, offline-first mosque donation and accounts app designed for use by different mosques.

## Planned first version
- Each mosque can enter its own mosque name and basic information.
- Bengali interface.
- Offline local database (SQLite).
- Monthly and yearly contributor records and collection entries.
- Income, expense, cash and bank ledger.
- PDF reports and data backup are planned.

This project is being built incrementally. Online sync is intentionally not included in the first version.
